# Tools

Every tool is implemented in `src/phase1/` and served over MCP by its agent's server: Financial Advisor on :8771, Payment Manager on :8772, Bank Agent on :8773. `message_bot` is Rakazo's built-in tool for messages between agents. All amounts are USD. "Scope" is `day` (today), `week` (today + 7 days) or `month` (today + 30 days). "Today" is the shared simulated clock in `data/clock.json`, which every tool reads on each call. A reset starts it at 09:00 today and shifts every bill and paycheck date by the same days; the seed and the examples below use 2026-10-24.

lookup_product: (Financial Advisor) Input `url` (Amazon link). Reads the fictional catalog `data/products.json`, matched by ASIN. Returns `{status: "found", url, name, price, source}` or `{status: "not_found", url, hint}`.
project_balances: (Financial Advisor) Input `price`, `fees_day`, `fees_week`, `fees_month`, `total_day`, `total_week`, `total_month`. Reads no data. Returns `{price, remaining: {day, week, month}}`, where remaining = total − fees − price for each scope.
list_wishlist: (Financial Advisor) Input `due_only` (bool, default false). Reads `data/wishlist.json` and the clock. Returns `{as_of, now, items: [{name, price, date, timestamp, deduction, reminder}]}`; with `due_only`, only items whose reminder date has arrived on the simulated clock.
add_to_wishlist: (Financial Advisor) Input `name`, `price`, `deduction` (general reason), optional `reminder`: `"week"` (today + 7, for "wait about a week"), `"month"` (today + 30, the default, for "wait about a month" or "not now") or a YYYY-MM-DD date. Writes the entry to `data/wishlist.json` with the simulated date and time; an item already on the list (same name, case-insensitive) is replaced, not duplicated. Returns `{saved: entry, updated: bool, wishlist_size}`. Errors on an empty name or reason, a negative price, or a reminder in the past.
remove_from_wishlist: (Financial Advisor) Input `name` (case-insensitive). Rewrites `data/wishlist.json` without that item. Returns `{removed: count, wishlist_size}`.
get_clock: (Financial Advisor) No input. Reads `data/clock.json`. Returns `{now: "YYYY-MM-DDTHH:MM", date, weekday}`, the simulated time every agent's tools use. No agent can move the clock: only the user's `python -m phase1.clock advance|set|reset` command does, which also runs the simulator (`phase1/simulator.py`). Moving forward receives the paychecks up to the new date and pays every unpaid bill due before it by autopay (marked paid in `data/payments.json`, debited in `data/accounts.json`, logged in `data/transactions.json` with `source: "autopay"`).
get_upcoming_fees: (Payment Manager) Input `scope`. Reads `data/payments.json`. Returns the unpaid bills due by the end of the scope, overdue ones included: `{scope, as_of, through, total, count, overdue_count, by_type: {type: amount}, payments: [bill]}`.
list_unpaid_bills: (Payment Manager) No input. Reads `data/payments.json`. Returns `{as_of, bills: [{id, type, fee, due, status, paid_on, confirmation}]}` for every unpaid bill, soonest first.
mark_bill_paid: (Payment Manager) Input `bill_id` (e.g. P01) and `confirmation` (the Bank Agent's TX-#### id). Sets that bill's `status` to paid with `paid_on` and `confirmation` in `data/payments.json`. Returns `{paid: bill}`. Errors on an unknown or already-paid bill, or a malformed confirmation.
spending_chart: (Payment Manager) Input `scope` (default month). Reads `data/payments.json` (all bills due in the scope, paid or not). Writes an SVG bar chart to `data/charts/spending_<scope>.svg`. Returns `{scope, total, share: {type: fraction}, by_type: {type: amount}, chart: path}`.
get_accounts: (Bank Agent) No input. Reads `data/accounts.json` plus the deposits in `data/deposits.json` that the simulated clock has reached (received paychecks). Returns `{as_of, accounts: [{bank, type, amount, goal?, apy}], current_total, savings_threshold}`.
get_projected_totals: (Bank Agent) No input. Reads `data/accounts.json` and `data/deposits.json`; deposits dated on or before today count as received, later ones as expected. Returns `{as_of, current_total, through: {scope: date}, expected_deposits: {scope}, expected_interest: {scope}, projected_total: {scope}}`.
check_savings_threshold: (Bank Agent) Input `day`, `week`, `month` (remaining totals). Reads `data/accounts.json` to compute the threshold, the sum of savings goals. Returns `{savings_threshold, checks: {scope: {remaining, above_threshold: bool}}}`.
debit_account: (Bank Agent) Input `bank`, `account_type` (checking or savings), `amount`, `reference` (bill id). Checks the current balance, received paychecks included. On success, lowers that account in `data/accounts.json`, appends `{confirmation, bank, type, amount, reference, date, timestamp}` to `data/transactions.json`, and returns `{status: "completed", confirmation: "TX-####", reference, amount}`. Otherwise returns `{status: "refused", reason, reference}` (invalid_request, duplicate_reference, account_not_found, insufficient_funds, below_savings_goal) and changes nothing.
message_bot: (all agents; built into Rakazo) Input the target bot name (`confirm_name`), message text and `intent` (request or result). Delivers the message to that bot's chat and starts its turn. The target's final reply is delivered back to the sender automatically. Returns a delivery acknowledgement.
